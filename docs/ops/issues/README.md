# Ops Issue Records

Create one issue record per meaningful user-visible or recurring operational problem.

File name:

```text
YYYY-MM-DD-<short-slug>.md
```

Use the issue template in `docs/ops/error-monitoring-workflow.md`.

Record P0-P2 issues immediately. Record P3 issues only when they recur or teach us something useful about prevention, logging, maintenance, or user experience.
