Cursor field & sound toggle

the Active Theory experience layer

Two halves of the same layer.
CURSOR: a ring that LERPS toward the pointer (factor 0.18) rather than
tracking it exactly — the lag is the effect. It grows and takes a label over
anything marked data-hot. Only mount on (pointer: fine); a custom cursor on
touch is dead weight.
SOUND: off by default and the choice is remembered. Browsers block autoplay,
so the toggle IS the unmute — never try to start audio before a gesture.
