## Overview

AVIntelligence is a Next.js application (App Router) integrated with Supabase and a custom security layer (`smart-security`).

## Primary Directories

| Directory | Responsibility |
|---|---|
| `app/` | Next.js routes, layouts, and global styles. |

| `paperclip/` | Autonomous operations agents (draft-and-approve). |
| `docs/` | Durable architectural and design documentation. |
| `supabase/` | Edge functions and database migrations. |

## Key Entry Points

- **Web Entry**: `app/page.tsx`
- **Security Middleware**: `proxy.ts`
- **Auth Flow**: `app/auth/`
- **Marketing**: `components/sections/`

## Data Flow

1. **Ingress**: Files pass through `prescan-document` -> `smart-security/v1/scan/file`.
2. **Session**: Requests filtered by `proxy.ts` -> `smart-security/v1/decide`.
3. **Processing**: Background tasks handled by `paperclip/` agents.

const fs = require('fs');
const path = require('path');

const DOC_PATH = path.join(process.cwd(), 'docs/architecture-map.md');

function scanFolders() {
  const rootItems = fs.readdirSync(process.cwd(), { withFileTypes: true });
  const folders = rootItems
    .filter(item => item.isDirectory() && !item.name.startsWith('.') && item.name !== 'node_modules')
    .map(item => item.name);
  
  return folders;
}

function updateDoc() {
  if (!fs.existsSync(DOC_PATH)) {
    console.error('Architecture map not found at ' + DOC_PATH);
    process.exit(1);
