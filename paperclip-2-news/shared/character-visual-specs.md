# Character Visual Specifications

The visual bible. Every Midjourney prompt, Inkscape trace, and SVG rig
references this file. Personality and voice live in `cast.md`; this file
is purely **how characters look**.

## Visual Recipe (universal)

- **Body proportions:** Persona 5 anime — tall slim, head ~1/7 body height,
  dramatic silhouettes recognizable from outline alone.
- **Surface treatment:** Octopath HD-2D pixel detail + Replaced cinematic
  lighting. Soft pixel detail in clothing/hair, cel-shaded with subtle
  gradients, atmospheric depth-of-field on backgrounds.
- **Color discipline:** 2–3 colors max per character. Silhouette + dominant
  color reads first, detail second.
- **Pose language:** Persona 5's "fashion-magazine static" — confident
  posture, deliberate stillness.
- **Silhouette test:** Every character must be recognizable in pure black
  silhouette. Failed silhouette = design adjustment required.

## Cross-Cutting Style Notes

1. **Silhouette test:** Each character recognizable in pure black silhouette. If silhouette fails, design adjusts.
   - Lana = curves + jewelry layers
   - Chip = leather jacket bulk
   - Compli-Anson = stooped politician + long nose
   - Sakura = bob silhouette + smart blazer
   - Apol = sharp bob + structured blazer
   - Cody = slick hair + suit lines
   - Grock = lean stiff suit + open collar
2. **Color block rule (Persona 5 discipline):** 2–3 colors max per character.
3. **Texture treatment:** Octopath HD-2D pixel detail for fabric, hair strands, skin shading. Subtle particles in environment (sakura petals around Sakura, sparkle around Gem, red rim around Grock).
4. **Lighting per character:** Each character has a signature lighting treatment:
   - Chloe: warm key light, even
   - Cody: bright presentation lighting (slight green wash from tie reflection)
   - Gem: bouncy multi-color sparkle
   - Grock: dramatic red rim
   - Deep: underlit, dark
   - Mistral: golden-hour Parisian
   - Lana: soft Instagram filter glow
   - Perp: bright daytime studio + footnote overlays
   - Sakura: soft spring light + sakura petal particles
   - Cole: cool blue (shifts the studio)
   - Chip: leather rim-light + green glow
   - Coral: golden autumn warmth
   - Apol: high-key Apple keynote bright
   - Ernie: red-and-gold rim
   - Compli-Anson: marble chamber softness
   - Nostram: harsh industrial overhead

## Legal Reminder

Per `legal-and-parody-guardrails.md`:
- All characters are **fictional**, parody silhouettes, never exact replicas of real people.
- Grock's "Musk-pattern" look = parody-distinct face. Same body type, hair pattern, NOT exact features.
- No real logos on outfits or backgrounds. Fictional brand marks only.
- Every character must pass the "would a reasonable viewer think this IS [real person]?" test. The answer must be no — they should read it as parody, not impersonation.
