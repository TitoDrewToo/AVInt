# Retired Smart Security scaffold

This directory belongs to the abandoned standalone Cloud Run and request-middleware architecture. Its schemas, policies, detection registry, service placeholders, and operational skill are not current product contracts.

The authoritative replacement is [`docs/smart-security-architecture.md`](../docs/smart-security-architecture.md), which defines Smart Security as AVIntelligence's integrated prescan security, rejection-evidence, and investigation capability.

The remaining non-document assets stay temporarily because the legacy health route imports this tree. Phase 1 of the replacement roadmap removes that route, verifies dependencies, and then removes this scaffold.
